# 去背景创意工坊候选项目：图片智能消除

## 状态

**📝 候选方案，待第三方 API 实测与需求验证（2026-09-26 更新）**

2026-09-26：用户确认将图片智能消除记录为「HBoot抠图去背景 → 创意工坊」的候选项目。此前按独立小程序构思的方案调整为现有产品内的扩展功能；暂不新建独立小程序或申请新 AppID。此记录不代表功能已开发、已上线或已通过审核。

当前只有产品边界、合规要求和技术方案，尚未接入第三方图片修复服务，也没有完成真实图片处理实验。未进入实现或验证前，不写成已完成的公众号文章，不加入正式产品列表。

暂定内部名称：**图片智能消除**

“去水印”只描述用户可能提出的一类需求，不作为“解析外部平台链接、下载无水印内容”的产品定位。

## 已确认方向

- 产品归属：HBoot抠图去背景；拟入口：创意工坊 → 图片智能消除。入口名称和位置属于方案，开发前再与当前页面结构核对。
- 只处理用户主动上传或拍摄的图片。
- 用户手动涂抹需要消除的区域，再提交处理。
- 可以处理用户有权编辑的文字、日期、Logo、杂物和画面瑕疵。
- 第一版接入国内第三方图像修复服务，不自行部署生成式修复模型。
- 使用用户协议、隐私保护指引和图片处理声明说明权利边界、数据用途和保存期限。
- 协议只用于明确规则，不能替代产品限制、隐私保护、投诉处理和平台责任。
- 用户主动同意协议后才能上传和处理，默认不勾选；服务端也校验同意状态。
- 第一版只做图片，不做视频逐帧处理。

## 明确不做

- 不解析抖音、小红书等外部平台链接。
- 不下载第三方平台上的图片或视频。
- 不自动识别并批量删除平台 Logo、作者账号或其他权利管理信息。
- 不提供恶意删除、篡改或隐匿 AI 生成合成标识的用途或宣传；该限制同时覆盖图片中的显式标识和文件中的隐式标识。
- 不提供“全网无水印下载”“搬运去重”或绕过平台查重的能力与宣传。
- 不建立公开作品库，不默认公开、分享或传播用户处理结果。
- 不把用户上传图片用于模型训练、广告素材或与本次处理无关的用途。
- 第一版不做批量处理、视频修复和长期云端相册。

## 产品判断

先作为现有去背景产品的创意工坊项目验证。拟复用用户身份、积分、任务记录、图片上传与保存能力，减少独立产品的维护和获客成本；具体接入点仍需检查当前实现。效果、用户需求、处理成本和审核条件验证后，再决定是否进入开发排期。

技术上可以通过第三方图像修复 API 快速验证，但通用“短视频无水印下载”存在明显的版权、不正当竞争和平台投诉风险。

《中华人民共和国著作权法》第五十一条限制未经权利人许可故意删除或改变作品上的权利管理信息。已有公开案例认定，开发和推广帮助用户去除短视频平台水印、进行内容搬运的小程序构成不正当竞争。

因此，产品应围绕“用户上传、自选区域、合法图片编辑”设计，而不是只在协议中声明用途、实际仍提供平台内容搬运能力。

参考：

- [中华人民共和国著作权法](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)
- [央视报道：开发推广去除短视频水印功能小程序牟利，一公司因不正当竞争被判赔](https://news.cctv.cn/2025/02/28/ARTIBH7DpVsRVRaY0tEj7zPt250228.shtml)
- [国家版权局：小程序侵权监管治理](https://www.ncac.gov.cn/xxfb/yjdt/201903/t20190304_49468.html)

当前没有找到微信公开规则中“所有去水印工具一律禁止”的明确条款，不把审核结果表述为必然。实际能否上线仍取决于功能、页面文案、隐私处理、投诉情况和当次审核。

本次补充的法律边界：现行《人工智能生成合成内容标识办法》第十条禁止恶意删除、篡改、伪造、隐匿生成合成内容标识，以及为上述恶意行为提供工具或服务。如果图片修复能力属于相关规定适用的生成合成服务，还需评估输出标识和相关材料要求，不能以用户同意协议或上游已合规作为自动免责依据。参考：[国家网信办《人工智能生成合成内容标识办法》](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)。

## 用户场景

第一阶段只验证以下场景：

- 删除自己照片上的拍摄日期或误加文字。
- 清理商品图、海报或截图中已获得授权的 Logo 和标记。
- 去除照片里的路人、小物件、污点或遮挡。
- 修复删除区域后的背景，使结果可以继续保存和使用。

产品不能判断用户是否真正拥有每张图片的权利，需要通过输入限制、显著提示、投诉渠道和处置机制降低滥用风险。

## 建议 MVP

```text
进入去背景创意工坊的图片智能消除入口
→ 阅读处理说明并主动同意协议、确认拥有本次处理所需权利或授权
→ 选择图片或拍照并上传
→ 手动涂抹需要消除的区域
→ 预览选区并提交
→ 第三方服务修复背景
→ 前后对比
→ 不满意时重新涂抹一次
→ 保存结果或立即删除
```

第一版功能：

- JPG、PNG 单张上传。
- 图片大小、分辨率和文件魔数校验。
- 服务端验证实际文件类型与图片解码结果，不仅依赖扩展名或客户端 MIME；检测到视频即拒绝，不创建修复任务，并清理已接收的临时文件。
- 画笔大小调节、撤销、重做和清空选区。
- 生成与原图对应的 mask。
- 异步处理状态、失败提示和有限次数重试。
- 原图与结果图对比。
- 保存结果与立即删除。
- 明确的版权投诉入口。

暂不预设免费次数、积分价格或广告位置。完成真实调用成本测试后，再决定使用免费体验、积分或按次购买。

## 第三方服务候选

以下候选信息沿用 2026-09-19 的记录，本次未重新核验供应商价格、额度和能力。实际接入前重新确认，并以真实调用结果为准。

### 腾讯云数据万象 ImageRepair

- 能检测并擦除图片中的常见标志，并对区域进行修复。
- 官方文档显示为付费服务，费用由数据万象收取。
- 需要进一步实测手动选区、透明图片、复杂纹理和大图的效果与费用。

参考：[腾讯云图像修复](https://cloud.tencent.com/document/product/460/79042)

### 火山引擎 veImageX 图像修复

- 支持自动检测常见图标或处理指定区域，并进行背景填充。
- 需要开通 veImageX 服务和智能处理计费。
- 如果已有火山云资源，可以作为首个测试候选。

参考：[火山引擎图像修复](https://www.volcengine.com/docs/508/2124618)

### 阿里云图像擦除补全

- 通过 mask 指定删除区域，可以处理人物、物体、文字和水印。
- 截至 2026-09-19，官方文档注明该模型主要提供免费体验，额度用完后不能直接付费调用，并建议参考其他图像编辑模型。
- 可以用于效果比较，不作为当前唯一生产依赖。

参考：[阿里云图像擦除补全](https://help.aliyun.com/zh/model-studio/image-erasure-and-completion)

正式接入前至少用同一组测试图片比较两家可生产付费的服务。业务后台必须通过统一 `provider` 接口调用，避免把任务模型、状态和计费规则直接绑定到一家供应商。

## 技术方案

作为去背景产品内的一种图片修复任务，拟复用现有 PostgreSQL、Redis、MinIO、身份与积分体系；通过独立任务类型区分抠图和智能消除，不让第三方服务直接接触小程序用户身份。复用范围与是否经统一能力平台调用 Provider，进入开发前再核对。

```text
去背景小程序 · 创意工坊
  → 服务端验证协议同意记录
  → 请求短期上传凭证
  → 原图上传私有 MinIO 桶
  → 提交选区 mask 与处理任务
  → Redis 队列
  → 图片修复 Provider
  → 第三方国内图像修复 API
  → 结果保存到私有 MinIO 桶
  → 小程序查询结果并保存
  → 到期自动删除原图、mask 和结果图
```

业务后台记录：

- 用户、任务、Provider 和请求标识。
- 输入尺寸、处理耗时、结果状态、失败原因和实际费用。
- 用户是否重新涂抹、是否保存结果。
- 删除时间和投诉处理状态。

日志不记录完整图片、签名地址、mask 内容或第三方返回的敏感原文。文件使用私有桶和短期签名地址；第三方密钥只保存在服务端。

## 协议与隐私文件

上线前至少准备：

1. 《用户服务协议》
2. 《隐私保护指引》
3. 《图片处理与版权声明》

上传操作附近使用简短确认：

> ☐ 我已阅读并同意《图片处理服务协议》，确认拥有本次图片上传与处理所需的权利或授权。

简短说明需显著写明：仅支持图片；持有、下载或购买图片不一定包含删除水印的授权；禁止未经许可删除或修改他人署名、版权声明等权利管理信息；禁止恶意移除 AI 生成合成标识。

同意流程要求：

- 复用现有产品协议体系，为智能消除功能补充专项说明，并同步更新隐私保护指引。
- 默认不勾选，用户可在同意前查看完整协议。协议同意与处理所需的其他法定授权分别处理，不以一个勾选代替全部授权。
- 未同意时禁止上传和创建处理任务；服务端校验当前适用协议版本，不能只禁用前端按钮。
- 记录用户、协议版本、同意时间，并让任务关联对应同意记录；保留各版本协议原文，明确本次图片处理的权利确认。
- 涉及用户权利义务的实质变更时，在继续使用本功能前重新提示并取得同意。
- 用户拒绝智能消除专项协议时，不影响其他无关功能；撤回同意后的停止处理和删除流程需明确。

协议需要说明：

- 服务只处理用户主动上传的图片。
- 用户应拥有图片或处理授权，不得侵犯著作权、肖像权、隐私权及其他合法权益。
- 禁止未经许可删除或改变他人作品的权利管理信息；不得将处理结果用于侵权传播、冒充原创或违法用途。不能把“未公开传播”写成允许删除权利管理信息的例外。
- 违反规则时可以停止任务、删除内容、限制账号并配合处理投诉。
- 处理效果受图片内容影响，不保证每张图片都能自然修复。
- 处理失败、额度返还、付费退款和服务中断规则。
- 权利人投诉渠道、所需材料和处理流程。

协议不能包含不合理免除平台责任、限制消费者权利或把全部责任转嫁给用户的格式条款。参考：[中华人民共和国消费者权益保护法](https://amr.sz.gov.cn/xxgk/zcwj/scjgfg/content/post_12816850.html)。

## 图片与个人信息处理

用户图片可能包含人脸、未成年人、证件、金融信息、家庭环境和其他个人信息。隐私保护不能只写“图片由用户自愿上传”。

需要明确告知：

- 收集的信息：用户选中的图片、涂抹 mask、处理结果和必要任务信息。
- 使用目的：完成用户发起的图片消除和修复。
- 第三方服务商名称、处理目的、数据类型、处理方式和存储地区。
- 原图、mask 和结果图的保存期限。
- 用户如何删除文件、撤回同意和联系开发者。
- 是否可能处理敏感个人信息，以及对应保护措施。

建议默认策略：

- 处理文件只保留完成下载所需的短期时间，初步建议不超过 24 小时，最终期限根据真实任务恢复和客服需要验证。
- 用户可以立即删除原图和结果图。
- 不用于训练，不公开，不建立长期作品库。
- 优先选择境内区域和境内第三方服务，第一版不做跨境传输。
- 与第三方约定处理目的、期限、方式、数据类型、删除和安全措施，并监督其处理活动。

《个人信息保护法》要求处理目的明确、范围最小、保存时间为必要的最短期限。微信小程序隐私保护指引也要求说明收集用户所选照片或视频的用途，并披露第三方服务商信息。

参考：

- [中华人民共和国个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)
- [微信小程序用户隐私保护指引内容介绍](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html)

## 需要验证的指标

第一轮不要只比较“看起来不错”的样张。为每个 Provider 使用相同测试集，记录：

- 任务成功率和平均处理时间。
- 单张真实调用成本。
- 第一次结果保存率。
- 用户重新涂抹率和平均重试次数。
- 每张最终保存结果的完整成本，包括失败调用、重试、存储和带宽；与该功能实际获得的收入比较，不用单次 API 报价代替成本。
- 进入功能、同意协议、上传、提交、保存的转化，以及再次使用和付费意愿；已有抠图产品的收入不能直接作为本功能的收益预测。
- 删除文字、日期、Logo、路人和普通物体时的差异。
- 纯色、渐变、纹理、人物边缘和透明图片的失败类型。
- 第三方超时、限流和内容审核拒绝情况。

测试集使用自有、已授权或公开许可图片，不使用来源不明的商业作品。

## 主要风险

1. 用户上传不代表平台可以忽略明显侵权用途，协议也不能成为完全免责工具。
2. “去水印”搜索意图可能主要来自内容搬运，与产品允许的合法图片编辑边界不一致。
3. 自动修复在文字覆盖人物、复杂纹理和大面积遮挡时可能生成错误内容。
4. 第三方按次或按量费用可能高于用户愿意支付的价格。
5. 图片可能包含敏感个人信息，泄露风险高于普通文本任务。
6. 第三方服务的价格、模型、限额和审核规则会变化，必须保留切换能力。
7. 即使没有明确的统一禁令，平台仍可能根据功能、宣传和投诉情况拒绝审核或要求整改。
