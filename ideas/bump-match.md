## 一句话玩法

在类似保龄球道的场地里，将随机颜色的铁块瞄准发射，利用碰撞和两侧墙壁反弹改变排列；远端磁力墙把铁块吸向场地深处，停稳后三个及以上相连的同色铁块消除。未消除的铁块持续在远端聚拢，堆积边界向玩家一侧延伸，达到红线则失败。

## 用户已经确定的方向

- 名称暂定为「碰碰消消乐」。
- 采用类似保龄球的 2.5D 画面：场地前方是已有的不同颜色方块，玩家在后方发射。
- 每次提供一个随机颜色的方块，玩家通过拖动瞄准位置并发射。
- 发射方块可以与场内方块碰撞。
- 场地左右两边为墙壁，碰到后可以反弹。
- 最后连接在一起的三个及以上同色方块会整组消除，不要求排成直线。
- 方块只在球道平面上移动和堆积，不上下叠放。
- 方块材质为铁，远端墙壁具有吸附作用；碰撞后的铁块会被吸向远端聚拢，减少向玩家一侧散落。
- 吸附过程有可见的磁力动画。
- 发射持续补充方块，未消除的方块向玩家一侧积累，达到红线则失败。
- 本次先整理玩法与开发方案。

## 场地关系

```text
                 远端磁力墙
           ┌────────────────┐
           │  蓝  红  黄  蓝 │
           │    黄  蓝  红   │
           │    ↑  ↑  ↑     │
    左侧墙 │                │ 右侧墙
     可反弹│    可用落点     │ 可反弹
           │                │
           ├──── 红线 ──────┤
           │       ↑        │
           │    当前方块     │
           └────────────────┘
                  玩家
```

上图是俯视逻辑示意。实际画面采用近大远小的固定视角，红线横跨球道，方块具有视觉厚度但不叠层。红线是判定标记，不是会挡住发射块的实体墙。

为避免“前方／后方”的视角歧义，本文统一使用“远端＝玩家对面的磁力墙”“近端＝玩家与发射区”。铁块向远端吸附，在地面上前后挤靠；堆积区逐渐变厚，边界才向近端红线扩展。

以下具体操作、数值与开发步骤为设计建议，供后续原型验证。

## 第一版核心循环

```text
看清当前颜色和场内分布
→ 拖动瞄准，查看方向与反弹提示
→ 松手发射一个方块
→ 铁块运动、碰撞、反弹
→ 磁力将铁块拉向远端，挤靠聚拢并停稳
→ 检查相连的同色块，执行消除
→ 剩余铁块继续受磁力牵引，向空处移动并停稳
→ 再次检查消除，直到不再产生连锁
→ 检查是否触线
→ 未失败则生成下一块，继续瞄准
```

每回合只允许一块新方块进入。上一回合未结算完成前不接受新发射，避免连续发射把“碰撞后哪些块相连”的规则掩盖掉。

“方块持续增加”先解释为每次发射带来一块，未消掉就留下。不额外加入按时间落块、每轮生成新排、整体自动推进等机制；这些需要另行确认。

## 瞄准和发射

第一轮原型建议固定发射点、固定发射速度，只让玩家控制方向，便于先判断碰撞与消除是否有趣。

- 玩家按住后方待发射方块，向场地内拖动瞄准。
- 方向线跟随手指，松开后沿该方向发射。
- 拖动距离过短、方向朝后或触摸被系统中断时取消发射，不消耗方块。
- 发射角度限制在朝向场内的范围，避免沿侧墙无限来回擦碰。
- 第一版最多预览一次侧墙反弹；遇到场内铁块后停止画线，不预测复杂的多体碰撞结果。预览使用与实际发射一致的磁力参数，不能在存在磁力加速时仍只画等角度直线折返。
- 2.5D 画面中的触摸坐标必须先换算到物理场地坐标，不能直接用屏幕角度计算反弹。

后续可单独测试“拖动距离决定力度”和“发射点左右移动”，不与基础方向操作同时加入。

## 碰撞与停稳

需要保留“碰过去会改变局面”的感觉。已有铁块能被推动和短暂撞散，随后受到磁力重新聚拢。磁力改变真实运动，不直接把铁块摆进预定格子。

- 同色、异色方块都参与碰撞；颜色只影响消除，不影响能否推动。
- 侧墙的反弹应明显可见，方块之间的碰撞要逐渐耗散能量，避免长时间抖动。
- 远端磁力墙同时是实体边界，使用较低反弹，减少铁块在吸附目标处反复弹开；近端的危险区与发射区分开。
- 方块采用有轻微圆角的方形外观；物理碰撞体应与外观接近，不能为了省事用相差很大的圆形碰撞体。
- 转动是否开放作为手感参数：保留转动可以产生自然堆积，但也可能让落点难以理解。用同一组测试局面比较后再确定。

建议用固定时间步推进物理计算。所有铁块的线速度和角速度持续低于阈值一小段时间，并已在磁力与接触阻挡下稳定后，才进入消除判断；仍在自由滑向远端的低速块不能提前休眠。阈值和等待时间在原型中调节。

设置异常运动超时保护，但不能直接在仍剧烈移动时强行结算。应先保留现场信息，检查穿透、卡墙或碰撞抖动，再决定是否对低速物体休眠。

## 磁力吸附

磁力的作用是让铁块持续向远端靠拢，为消除后的空位提供自然补位，也让未消除的铁块形成可理解的堆积压力。

### 力的方向与作用对象

- 磁力墙是一整面横墙，吸引方向统一朝向远端，不把所有铁块拉向墙面中央的一个点。
- 所有已发射铁块都受影响，无论颜色；还在等待区、跟随手指瞄准的方块不受磁力影响。
- 铁块之间只进行普通碰撞，不增加同色相吸、异色相斥或铁块互相吸引的规则。
- 铁块遇到墙或其他铁块时受到阻挡，不能穿透前排去贴墙，也不传送到空隙中。
- 消除后，受影响的铁块重新唤醒并继续受磁力牵引；向远端确实存在可达空位时才会移动，允许留下被其他铁块挡住的空隙。

### 第一轮手感建议

先采用有限、稳定的朝远端加速度，不模拟复杂磁场，也不使用靠墙时无限增大的吸力。

- 新发射铁块在首次碰到场内铁块或远端墙之前使用较弱吸力，保留瞄准与借侧墙反弹的控制感。
- 首次撞到铁块、远端墙，或已明显减速后，平滑切换到正常吸力，避免铁块慢慢停在球道中间。
- 场内已经聚拢的铁块保持正常吸力，受到撞击后可以暂时位移，再回到受阻稳定位置。
- 磁力与阻尼共同调节：磁力负责拉回远端，阻尼负责消散横向、旋转和回弹运动。强度在试验中确定，不预先承诺某个数值能完全消除回弹。

“弱吸力发射、正常吸力归拢”是待验证的实现建议，核心要求仍是碰撞后能向远端聚拢。允许铁块碰撞时短暂向近端移动；目标是避免它们最终散落在发射区，而不是强行取消所有朝近端的速度。

### 吸附动画

- 磁力墙做成金属电磁装置，使用发光线圈或灯带表明它在工作。
- 地面显示少量向远端流动的短线或粒子，方向与实际吸力一致。
- 铁块明显被吸回时，侧边出现短促高光与朝远端的拖尾；撞击时有轻微金属音与短暂震动反馈。
- 消除后补位时，磁力墙灯带轻微脉冲一次，让玩家看出剩余铁块移动的原因。
- 稳定堆积时减弱流动效果，保留低亮度灯带，避免画面一直闪动。
- 磁力效果不能盖住铁块颜色、连接边缘和红线。动画读取实际吸附状态，不用假动画把静止铁块画成移动，也不等待粒子播放完才推进物理结算。

## 连通消除

消除依据物理位置与接触关系，不依据画面看起来是否重叠，也不强制吸附到棋盘格。

- 只有颜色相同、并在停稳后实际接触或处于很小接触容差内的方块才建立连接。
- A 连 B、B 连 C 时，三者属于同一连通组，即使 A 不直接碰 C。
- 中间隔着异色块不能连接；快速擦过同色块不立刻消除。
- 对每种颜色建立接触关系，再查找连通组；数量达到 3 个的组整组消除。
- 建议同时结算本轮所有达标组，避免遍历顺序改变结果。
- 首次场地生成时不放入已达门槛的连通组，防止玩家尚未出手就自动消除。

消除后让剩余铁块在磁力作用下重新聚拢，稳定后检查下一组。磁力补位可以产生连锁，但不保证每次消除都会补满所有空隙；不使用瞬移、吸格或跨越障碍的自动排齐。

例如：发射一个蓝块，停稳后将两个原本分开的蓝块连接起来，三块一起消除。只碰到一个蓝块时两块都留下；即使发射的是红块，如果它把三个蓝块推成一组，蓝块也可以消除，红块留下。后一条采用“检查全部达标组”的结算建议，原型中应单独验证玩家是否看得懂。

## 失败与压力来源

先完成本回合磁力归拢、消除、补位和可能的连锁，再检查失败。飞行中的方块经过危险区域，或刚碰撞时短暂越线，不应直接判负。

- 红线是一条横跨球道的危险边界，位于已有方块与玩家发射区之间。剩余方块停稳并完成消除后，其实际碰撞体伸到红线或更靠近玩家的位置即失败。
- 新发射方块会从红线后方出发并穿过红线，运动阶段不触发失败。若它最终停在红线后方且没有消除，同样判负。
- 未发射、仍在等待区的当前方块不参与失败判定。
- 失败后明确高亮触线方块，并保留局面让玩家看懂原因。

第一轮使用固定的初始局面和少量颜色。初始铁块需要先完成磁力归拢，再验证不存在达标的同色组。压力来自“远端可用空间逐渐被占满”：铁块虽然被拉向远端，但无法穿过前排，因此新增铁块会逐渐挤到近端红线。先不叠加倒计时或额外障碍。

## 视觉与反馈

- 竖屏构图，玩家在近端看向远端球道，远端略窄，形成类似保龄球道的纵深。
- 铁块用金属倒角、侧面反光和落地阴影表达体积，顶面保留清晰的彩色涂层；场地、磁力墙、危险线、发射区清晰分层。
- 颜色之外增加简单符号或纹样，使相邻的不同颜色在小屏上也能区分。
- 当前待发射颜色应突出显示；是否展示下一块留作原型参数。
- 危险线要始终可辨，不被方块或透视阴影完全遮住。
- 发射、撞墙、撞块、吸附、消除分别使用短促而不同的反馈，磁力动画与归拢过程同步。

## 开发方案

### 二维物理与 2.5D 显示

已确认采用平面堆积，因此物理模拟只需要二维地面坐标与平面旋转。

- 使用二维刚体处理位移、旋转、碰撞和反弹；地面重力设为零，以独立的朝远端作用力实现磁吸，通过阻尼或摩擦耗散运动能量。
- 渲染时将地面坐标投影成有纵深的画面，给方块增加侧面与阴影，按远近顺序绘制。
- 逻辑场地始终是两侧平行的矩形。画面中的梯形透视只用于显示，不把两侧墙误做成物理上越走越窄的漏斗。
- 瞄准线、墙壁、方块、红线共用一套投影；指针输入使用对应的逆变换。
- 不引入垂直抛物线、重力堆高或方块跳到其他方块上方的规则。

具体引擎待原型平台确定后选择。优先验证二维刚体碰撞、接触读取、固定时间步、触摸输入和目标平台运行能力，不在本次方案中锁定未核验的引擎版本。

建议采用 TypeScript 编写回合规则与数据，物理适配和显示独立封装。若后续确定微信小游戏，再验证目标引擎的小游戏构建、包体与真机表现。

### 模块边界

| 模块 | 职责 |
| --- | --- |
| 回合控制 | 瞄准、发射、运动、消除、连锁、失败的状态切换 |
| 输入控制 | 触摸坐标转换、瞄准、松手与取消 |
| 物理场地 | 方块、墙体、碰撞、反弹、摩擦与停稳判断 |
| 磁力控制 | 朝远端作用力、发射与归拢阶段的强度、消除后的唤醒 |
| 连通判定 | 从最终接触关系找到同色连通组 |
| 发射队列 | 当前颜色、可选的下一块预告、随机种子 |
| 失败判定 | 红线与结算后剩余方块的关系 |
| 显示与反馈 | 金属 2.5D 画面、方向线、磁力流动、消除动画、音效 |
| 回放记录 | 初始局面、随机序列、每次发射方向与结果 |

消除规则读取物理状态，显示读取规则结果。不要由动画结束回调分散修改分数、方块数组和回合状态。

## 原型开发顺序与验收

| 阶段 | 交付物 | 必须验证的结果 |
| --- | --- | --- |
| 1. 发射试验 | 球道、单个铁块、磁力墙、侧墙、瞄准线 | 直射与借墙反弹预览符合磁力下的实际运动，有效拖动松手发射，取消操作不误发射 |
| 2. 碰撞归拢 | 少量可推动的铁块、磁力与阻尼 | 撞散后向远端聚拢，不穿透、不过度抖动，能在合理时间停稳 |
| 3. 消除闭环 | 连通查找、消除、磁力补位 | 同色传递连接有效，擦过不消除，补位可产生下一轮消除 |
| 4. 整局循环 | 随机供块、危险线、失败、重开 | 远端堆满后逼近红线；磁力归拢与连锁完成后才判负 |
| 5. 视觉与试玩 | 金属铁块、磁力动画、调参入口 | 玩家能看懂反弹、吸附、连接和失败的因果关系 |

先完成单发射与多体碰撞试验，再估算后续工作量；目前未运行原型，不把计划当作已验证的开发工期。

## 第一轮参数与测试局面

这些数字是用于比较手感的起点，不是确定的产品数值。

- 先用 3 种颜色，验证后再比较 4 种颜色的压力。
- 球道宽约 8 个方块边长，远端到红线约 10 个方块边长；发射点在红线后另留空间。
- 初始放置约 12～18 块，分布在远端；在磁力作用下稳定后，不含三个同色连通组。
- 当前颜色从场内仍存在的颜色中随机抽取，先减少没有同色目标可打的回合；是否纯随机扩展到完整调色板，等难度测试后再决定。
- 若全部方块消完，原型先显示“清场成功”，提供重开，不暗中补排。无尽补场属于后续规则。
- 先只给当前方块，预告下一块作为可切换参数，用相同局面比较规划空间。

固定测试局面至少包括：直射三连、借一次侧墙三连、异色阻隔、通过推挤连接其他同色块、只连成两块、触线后因消除获救、消除后仍有方块触线失败。

磁力专项测试：被撞向近端后拉回、消除前排后补位三连、前排挡住时不穿透吸墙、已稳定的密集堆积不持续抖动、侧墙反弹预览与实际轨迹一致，以及吸附归拢后仍因满场触线失败。

记录随机种子、发射方向与关键物理快照。相同种子不保证不同平台的物理计算完全一致，必要时用快照定位差异，不声称已经具备跨平台确定性回放。

## 第一版范围

- 一个场地、一种彩色铁块、少量基础颜色、一面远端磁力墙。
- 拖动瞄准、单发射、侧墙反弹、方块碰撞。
- 磁力归拢、消除后补位，以及清晰的磁力动画。
- 停稳后的同色连通消除。
- 持续供块、红线失败、得分、重开。
- 固定种子的测试局面和可调参数。

先不做账号、排行榜、道具、广告、复活、剧情、皮肤、每日任务或后台。

## 需要通过试玩回答的问题

- 玩家能否预测一次借墙反弹的大致落点？
- 碰撞造成的移动是在帮助玩家制造连接，还是让结果难以理解？
- 方块接触边界是否符合肉眼判断？尤其检查角对角接触和小缝隙。
- 未消除后的累积能否产生压力，同时仍保留可选落点？
- 在三连门槛下，颜色数量与随机序列是否让玩家有选择，而不是只等待某一种颜色？
- 一回合是否等得太久？需要调整摩擦与休眠，还是减少初始方块？
- 磁力能否收拢铁块，同时保留侧墙反弹和不同瞄准方向的价值？
- 玩家是否能分清碰撞造成的位移与磁吸补位，理解由补位引发的连锁？

先验证瞄准、碰撞、磁吸、停稳和消除的因果关系，再决定是否进入正式产品开发。
