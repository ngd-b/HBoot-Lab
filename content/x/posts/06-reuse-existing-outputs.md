# 06｜Reuse existing outputs

- 日期：2026-08-25
- 状态：已发布
- 实际时间：待补充

## English

> Before adding another feature, ask: can the output users already created become the input to their next task?
>
> A background-removed photo can become an ID photo, sticker, avatar, or poster.
>
> Reuse reduces uploads, waiting, and repeated work.

## 中文

> 增加新功能之前，可以先问：用户已经生成的结果，能不能直接成为下一项任务的输入？
>
> 一张去掉背景的照片，还可以继续制作证件照、贴纸、头像或海报。
>
> 复用能够减少重复上传、等待和处理。

## 配图

建议使用同一张透明背景人物制作四种结果：`Transparent image → ID photo / Sticker / Avatar / Poster`
