# 44｜Which result should win?

- 日期：2026-09-16
- 状态：已发布

## English

> Retries recover failed jobs—but can overwrite a user’s correction.
>
> I keep the user’s edit, even if a later retry might produce better data. It prevents silent overwrites but may discard a useful correction.
>
> Which should win: the user edit or the newest result?

## 中文校对

> 重试能恢复失败任务，但也可能覆盖用户的修改。
>
> 我选择保留用户修改，即使后续重试可能得到更好的数据。这样能避免静默覆盖，却也可能丢掉一次有用的修正。
>
> 你会让哪一个结果优先：用户修改，还是最新处理结果？

## 配图

纯文字发布。现有产品界面不能直接证明重试时如何保护用户修改和删除结果，配图无法提供比正文更有效的证据。

## 发布依据

- [第 18 期公众号文章](../../wechat/自动记账靠不靠谱，先检查这四点.md)记录了已入账流水支持修改和删除，系统重试不能覆盖用户改过的内容，也不能把删除的记录重新写回。
- 同一文章的发布依据记录了来源关联和用户级业务锁用于防止任务重试、页面并发及前后台同时处理时重复写入。
- 正文基于已经完成的“保留用户修改”行为展开取舍；“后续重试可能得到更好的数据”是对设计代价的假设，不是已观察到的产品数据。
