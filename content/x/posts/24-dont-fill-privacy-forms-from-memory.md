# 24｜Don’t fill privacy forms from memory

- 日期：2026-09-06
- 状态：已发布

## English

> Filling out a privacy form from memory is asking for trouble.
>
> Before submitting my app for review, I had AI scan the code and list every place it accesses user data: what it collects, where it’s used, and why.
>
> Then I used that list to complete the privacy declaration instead of relying on memory.

## 中文校对

> 靠记忆填写隐私声明，很容易漏项。
>
> 提交应用审核前，我让 AI 扫描代码，列出每一处获取用户数据的地方：获取什么、在哪里使用、为什么需要。
>
> 然后我按照这份清单填写隐私声明，不再依赖记忆。
