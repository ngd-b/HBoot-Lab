# 04｜Three rules for ads in utility products

- 日期：2026-08-30 21:30
- 状态：待发布

## English

> A simple rule for ads in utility products:
> - browsing: use natural pauses
> - doing: don’t interrupt
> - ad failure: the core task must still work
>
> Never hold a result the user already created hostage behind an ad.

## 中文

> 工具类产品可以用三条规则判断广告位置：
> - 用户正在浏览：放在自然停顿处
> - 用户正在操作：不要中途打断
> - 广告加载失败：核心功能仍然可用
>
> 不要把用户已经完成的结果扣在广告后面。
