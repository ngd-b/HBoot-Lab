# 01｜Build for the task, not the demo

- 日期：2026-08-25
- 状态：已发布
- 实际时间：待补充

## English

> An AI feature is not a product workflow.
>
> For an invoice tool, OCR is only step one. Users still need to import files, split multi-page PDFs, fix mistakes, remove duplicates, filter records, and export originals.
>
> Build for the task—not the demo.

## 中文

> 一个 AI 功能，并不等于一条完整的产品工作流。
>
> 对发票工具来说，OCR 只是第一步。用户还需要导入文件、拆分多页 PDF、纠正错误、删除重复记录、筛选数据和导出原件。
>
> 应该围绕用户的任务开发，而不是围绕演示效果开发。

## 配图

建议制作横向工作流图：`Import → OCR → Split → Review → Deduplicate → Filter → Export`
