# 从 0 做产品 05｜两个月里，我怎么把它做上线？

- 状态：待拍摄

## 口播母版

《智能去背景》从开始到上线，我做了大约两个月。

对一个前端开发者来说，中间有很多第一次：第一次跑通 AI 模型，第一次写 Python 服务，第一次把服务放到自己的服务器，再到 Docker、数据库、HTTPS、自动部署和小程序备案。

如果把它们同时看成一个项目，会很容易放弃。我只关心下一个可验证节点：模型先跑起来，接口再拿到结果，小程序最后跑通上传到展示。

大项目不一定要用意志力硬撑。把它拆成每次都能看见结果的小节点，开始会容易很多。
