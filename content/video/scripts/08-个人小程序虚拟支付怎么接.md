# 从 0 做产品 08｜个人小程序怎么接入虚拟支付？

- 状态：已发布
- 观众看完知道：自己的个人小程序是否具备虚拟支付资格、接入要跑通哪些环节，以及道具配置、登录态和发货中最容易出错的地方。

## 口播母版

个人小程序怎么接入虚拟支付？

我的小程序「智能去背景」已经接入虚拟支付了。现在打开积分页，就能直接选择购买积分包，使用微信支付，iOS 平台可以使用 App Store 进行支付。

开通有什么条件？首先小程序的服务类目要包含工具，然后就是通过认证和完成备案，申请接入时只需要填写个人身份信息和本人的银行卡信息提交等待审批即可。

我这次审核很快，一两分钟就通过了。接着扫码签约，完成后再在小程序内接入。官方提供了接入用的 Agent 提示词和 Skill，这次我选择复制提示词，交给 Agent 完成接入。

目前个人小程序只支持道具购买，而且调用参数是固定的，无法修改。可以在后台基本配置-道具配置中，先在开发版本里创建道具并进行审核，没问题后进行发布，就可以在线上版本看到道具了。

iOS 支付需要在“基本配置—基础配置”中开启，iOS 的手续费是 12%。

最后还有一个很重要的是需要添加支付回调，用户支付完成后，平台会调用通知接口完成支付，然后服务端再发送道具包给用户账号。这个是需要配置的，再开发管理-消息推送开启。
