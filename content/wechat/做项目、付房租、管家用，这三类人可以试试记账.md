# 做项目、付房租、管家用，这三类人可以试试记账

每个月给服务器续费，想知道自己做的产品到底投入了多少钱；交完房租和水电，想弄清剩下的钱花在了哪里；家里的菜和日用品一直由你买，却说不清一个月总共花了多少。

这些时候，记账就有一个具体的用途：把自己负责的那笔开销算清楚。

**一、做产品、做生意的人：项目花了多少，实际收回多少？**

独立开发者会买域名、租服务器、付模型 API 费用，还可能开着几个软件订阅。刚开始创业，也会陆续付样品、设计、外包和推广费用。

单看每一笔都有印象，真要算这个项目累计投了多少，却得重新翻几处付款记录。尤其是费用从自己的生活账户里付出去，很容易混在一起。

可以给项目单独建一个账本，把自己经手的费用分好类，再记下实际收到的收入。回看时就能知道钱花在了哪些地方，这个月付出了多少、收回多少。几个项目共用的服务费用单独记录，避免重复记账。

**二、自己承担生活开销的人：一个月正常生活，到底要花多少？**

自己租房、上班以后，房租是一笔固定开销，水电、通勤、午饭、外卖和日用品则是一笔笔往外付。

这个月花得多，是刚搬家买了家具，还是平时吃饭、打车就花了这么多？只看付款总额，不容易分清。

把住房、餐饮、交通、日用品分开记，再按月看分类支出，就能慢慢摸清自己的生活开销。想控制外卖或打车费用，也可以单独设一份分类预算，看已经花了多少、还剩多少。

**三、负责家庭开销的人：每天都在买，家里一个月花多少？**

今天买菜，明天补牛奶和水果，周末去超市买洗衣液、纸巾和米面油。有孩子的家庭，还要买纸尿裤、衣服；养宠物的，要添猫粮、狗粮和日常用品。

每样东西单独问，可能都知道价格。可一到月底，想算家里这段时间的日常花费，就只能估个大概。

把自己负责的这些开销记下来，按食品、日用品、孩子、宠物等分类回看，就能分清平时花了多少，哪些是偶尔的大额支出。以后安排生活费，或者回查某一笔购买记录，也有依据。

我做的 **「小票智能分类记账」**，可以用来整理这些收支：建立多个个人账本，自定义分类，查看月度统计和预算。
