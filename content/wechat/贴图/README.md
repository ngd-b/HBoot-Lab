# 小程序公众号贴图宣传

公众号贴图单独存放于本目录。标题、正文、图片、发表操作和依据保存在每篇文案内，图片按主题放入 `assets/`，状态统一记录在[发布计划](公众号贴图发布计划.md)。

本批已准备 6 篇，覆盖「HBoot抠图去背景」「HBoot场景外语学习」「小票智能分类记账」，第 01–04 篇已发布，其余 2 篇待发布。

## 使用方式

1. 从发布计划打开一篇文案，复制“发布标题”和“发布正文”。
2. 上传“上传配图”中列出的原文件，按编号排序。
3. 插入对应小程序卡片，确认预览可以打开目标页面，并手动添加 `#来微信做个小程序`。
4. 发表后补录时间、链接和状态；按计划记录可获取的数据。

“依据与素材说明”供内部核对，不复制到公开正文。实际小程序卡片需要在公众号编辑器中插入，文案中的产品名称不能代替链接。

后续公众号贴图继续存入本目录，长文仍保留在上一级目录。
