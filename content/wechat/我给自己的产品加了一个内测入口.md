# 我给自己的产品加了一个内测入口

我在自己的统一认证平台里，做了一个产品内测管理功能。

**产品正式开放前，可以先给指定用户开通 Web 测试资格，设置有效期，再在后台统一管理。**

【此处插入产品后台的“测试用户”管理截图，发布时删除本占位文字】

一个产品已经能用了，想先找几个人试试，可以把它设为“测试”状态。产品仍然可见，但 Web 登录只对平台管理员和有测试资格的用户开放。

接下来，在后台打开这个产品的“测试用户”，从已注册的统一账号中搜索、勾选用户，就能批量添加资格，不用逐个填写。

每次授权可以设置到期时间，也可以留空，保持长期有效。比如只开放一周测试，就填好结束时间；想让几位用户持续参与，就保留长期资格。

已经获得资格的人，也有单独的列表可以查看。需要调整时，可以修改有效期；不再参与测试，就移除资格。移除后，该用户在这个产品的 Web 登录会话也会被撤销。

准备正式开放时，把产品状态切到“上线”，Web 登录就对普通用户开放了。如果设为“禁用”，则停止产品访问。

**统一认证做起来以后，这类功能就方便集中管理了。**

测试者使用已有的统一账号，我在「HBoot统一登录」后台选中对应产品，就能管理它的测试名单、期限和开放状态。几个产品都接进来后，可以在同一个后台操作，新增产品也能沿用这套内测管理。

账号统一，资格仍按产品分开。同一个人可以参与多个产品的测试，各自设置期限；撤销某个产品的资格，不影响他在其他产品的资格。

对我来说，统一认证的优势就在这里：账号、登录和访问资格有了共同的管理基础，后面加功能时，能让接入的产品一起复用。

这里控制的是 **Web 产品的登录访问**。微信小程序的体验版、审核和发布，仍由微信侧管理。

接下来可以按这套流程安排产品试用：**设为测试 → 添加测试者 → 设置期限 → 测试后正式开放。**
