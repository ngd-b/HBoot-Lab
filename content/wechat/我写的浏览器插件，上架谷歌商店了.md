# 我写的浏览器插件，上架谷歌商店了

想混英文区、日语区、韩文区，看看大家在聊什么，也参与几句，但语言不懂，怎么办？

看帖子可以翻译，可想回复时，又得把自己的意思组织成对方的语言。遇到几个人来回讨论，还要先弄清楚前面说了什么，才知道这句话该怎么接。

我开发的浏览器插件 **Reply Assistant**，就是用来帮助你读懂外语对话，再把自己的想法表达出来。现在已经上架谷歌 Chrome 扩展商店。

【此处插入 Chrome Web Store 上架截图，发布时删除本占位文字】

**拿 X 上的讨论举个例子。** 看到一条英文、日文或韩文帖子，想问一个问题，或者聊聊自己的看法，可以在帖子旁打开助手。当前商店版先支持 X，下面用这个场景介绍操作。

打开以后，先核对它读取的原文和对话，再翻译成自己选择的阅读语言。正文和引用分别显示，也能展开原文对照。遇到一段来回讨论，可以查看已加载的前序消息，确认现在是在回复谁、前面谈了什么。

看懂以后，可以用中文在回复意图里写下自己想说的话。比如想问一个细节，或者补充一个不同的看法，再选择英语、日语或韩语等回复语言，点击生成回复。

插件会结合对话和你的补充，生成最多三条候选。你可以选择、修改，检查字数，再复制到 X 发布。**阅读语言和回复语言分开选：用中文看懂，用对方的语言参与。**

**回复由你决定什么时候生成、怎样修改和是否发布。** 插件不会自动填入或发送，也不会批量替你评论。

操作都放在一个悬浮窗口里，可以拖动、调整大小、最小化，也能切换单列和双列。看对话和准备回复时，可以把它放在顺手的位置。

使用前，需要在设置里配置自己的模型服务和 API Key，再选择阅读与回复语言。翻译和生成调用的是你配置的服务，可能产生对应的 API 费用；插件本身不提供模型额度。

它读取的是页面里可用的文字，不会自动分析图片、视频或未加载的消息。对话缺了一段，可以自己补充；生成内容也要看一遍，确认没有误解原意，再发出去。

现在可以从 Chrome Web Store 安装 Reply Assistant。想参与英文区、日语区或韩文区的讨论，可以先在 X 上选一条自己感兴趣的公开帖子，翻译读懂，再用中文写下自己的想法，试着准备一条回复。
