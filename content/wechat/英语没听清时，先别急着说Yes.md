# HBoot-Lab #034｜英语没听清时，先别急着说 Yes

电话会议里，对方说了一长段话，最后问你：“Did you catch that last part?”——刚才那部分听清了吗？

你只听到了几个词，还没弄明白，却顺口回了一个 Yes。

对话是继续了，但没听清的那部分也被带过去了。如果里面恰好有一个时间、一项安排，后面还得再找机会确认。

准备英语时，我们容易先练“我要怎么介绍自己”“我要怎么提要求”。也可以给自己准备一句：**没听清的时候，我怎么请对方再说一遍？**

不用绕很长的句子，可以先说：

**Could you repeat that last part?**

能重复一下刚才那部分吗？

这句话把范围说清楚了：前面听到了，只需要再听最后一部分。如果整句话都没听清，可以说 **Could you repeat that?** 不必把自己没听懂的原因解释一遍，先把缺的内容听完整。

在「HBoot场景外语学习」的“职场英语 · 电话会议”场景里，有一段音频断续的对话。对方问有没有听清，你可以这样接：

> Sorry, you're breaking up a bit. Could you repeat that last part? I want to make sure I got it right.
>
> 抱歉，你的声音有点断断续续。能重复一下刚才那部分吗？我想确认我理解正确。

这里要留意，**you're breaking up** 说的是通话声音断断续续。如果声音很清楚，只是自己没听懂，直接用后面的请求重复就好，不需要照搬整句。

请对方重复之后，还可以把关键内容单独确认一下。

比如，你不确定听到的日期是不是周五，可以问：**Did you say Friday?**——你刚才说的是周五吗？这只是一个确认日期的例子，实际用时换成你需要核对的词。

这样，对方能知道你卡在哪里，你也不用带着一个模糊的印象继续往下聊。

练习时，可以把这次目标缩小：先把“请求重复”这一句练顺。在「场景外语学习」里打开电话会议场景，找到对应句子，听一遍原音，再按住录音跟读。长句跟不上，可以调整播放语速，先听清词句之间怎么连接。

跟读后，再试一次不看文字：想象对方刚说完，而你没听清最后一句，自己开口接上 **Could you repeat that last part?**

跟着读顺了，不代表已经能听懂真实会议。这个练习先解决一件小事：遇到听不清的时候，有一句话能让你继续问下去。

下次准备面试、开会或出行英语，除了想好自己要说什么，也留一句用来请对方重复。真没听清时，就把需要确认的地方问出来。
